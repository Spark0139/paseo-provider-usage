Open a product’s quota card beside the composer in an existing conversation, or open Provider Usage in the sidebar to see all products for this host. The cards show Codex quotas from CPA Usage Keeper, Claude Code subscription windows and the daemon’s Antigravity quota pools. Hover, focus or tap a reset time to see the full Chinese date and local time zone. Keeper and Claude readings also appear in Paseo’s global Usage view.

The Codex card uses account aliases and notes from Keeper, with separate sections for multiple instances. Add each Keeper instance URL in settings, including its path prefix. Enter a Keeper password if the instance requires login. The overview and open Codex card reread the cache every minute and show when Keeper observed the quota. To request a new observation, click the update button on that instance once. The plugin follows the batch of enabled Codex accounts and displays the result.

To collect Claude quota, select one Claude provider and put the supplied Node.js launcher before its existing command. A normal Claude Code or ReClaude session updates the readings when it emits a subscription quota event, including the Fable weekly window when reported. Antigravity uses the sign-in and launch environment configured in its Paseo provider. You can switch off the Antigravity view in settings. When enabled, it selects Antigravity reports from a host-wide Paseo 0.17.4 usage request that may update other native sources or reuse a five-minute cache.
