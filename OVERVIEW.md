The composer shows the remaining quota for your preferred Codex account and for Claude. Open a product’s card to see its quota windows and local reset times, or open Provider Usage in the sidebar to see all products. Keeper and Claude readings also appear in Paseo’s global Usage view.

Add each Keeper instance URL in settings, including its path prefix and a password if the instance requires login. Choose the Codex account you want to see beside the composer. The full card groups all accounts by instance and uses their Keeper aliases or notes. The visible Codex pill, card and overview sync Keeper’s cache every minute. To request a new observation, click the update button on that instance once. The plugin follows the batch of enabled Codex accounts and displays the result.

To collect Claude quota, select one Claude provider and put the supplied Node.js launcher before its existing command. A normal Claude Code or ReClaude session updates the readings when it emits a subscription quota event, including the Fable weekly window when reported. Antigravity uses the sign-in and launch environment configured in its Paseo provider. You can switch off the Antigravity view in settings. When enabled, it selects Antigravity reports from a host-wide Paseo 0.17.4 usage request that may update other native sources or reuse a five-minute cache.
