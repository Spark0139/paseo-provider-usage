Provider Usage shows Codex quotas from CPA Usage Keeper, Claude Code subscription windows and the daemon’s native Antigravity usage reports in the sidebar. Hover, focus or tap a reset time to see the full Chinese date and local time zone. All three cards use the Usage Monitor Codex bar layout. The Antigravity card groups the reported windows by quota pool. Keeper and Claude readings also appear in Paseo’s global Usage view.

The Codex card uses account aliases and notes from Keeper, with separate sections for multiple instances. Add each Keeper instance URL in settings, including its path prefix. Enter a Keeper password if the instance requires login. The panel reads cached quota and shows when Keeper observed it. To request a new observation, use the update button on that instance. It submits the enabled Codex accounts in one batch. Read the cache again after Keeper processes the queue.

To collect Claude quota, select one Claude provider and put the supplied Node.js launcher before its existing command. A normal Claude Code or ReClaude session updates the readings when it emits a subscription quota event, including the Fable weekly window when reported. Antigravity uses the sign-in and launch environment configured in its Paseo provider. You can switch off the Antigravity view in settings. When enabled, it selects Antigravity reports from a host-wide Paseo 0.17.4 usage request that may update other native sources or reuse a five-minute cache.
